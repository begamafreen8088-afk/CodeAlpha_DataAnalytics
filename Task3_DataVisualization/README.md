# CodeAlpha Task 3 - Data Visualization

## 📊 Project Overview

This project focuses on transforming a raw book dataset into clear,
professional, and meaningful visualizations using Python.

The visualizations were created using Pandas, Matplotlib, and Seaborn
to communicate patterns and insights related to book prices and ratings.

## 🎯 Objectives

- Transform raw data into visual formats.
- Create professional charts and graphs.
- Identify patterns and trends visually.
- Compare book prices and ratings.
- Examine the relationship between price and rating.
- Present findings through effective data storytelling.
- Create a portfolio-ready visualization dashboard.

## 🛠️ Technologies Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 Dataset

The dataset contains 20 books with the following columns:

| Column | Description |
|---|---|
| Title | Name of the book |
| Price | Price of the book |
| Availability | Stock availability |
| Rating | Rating from One to Five |

## 📈 Visualizations Created

The notebook contains:

1. Book Price Ranking
2. Book Rating Composition
3. Average Book Price Trend Across Ratings
4. Top 5 Most Expensive Books
5. Price vs Rating Scatter Plot
6. Professional Data Visualization Dashboard

## 🔍 Key Insights

- Book prices vary considerably across the dataset.
- The dataset contains books with ratings from One to Five.
- The price-rating relationship is weak in this dataset.
- All books in the dataset are listed as in stock.
- The dashboard provides a compact visual summary of the dataset.

## 📖 Data Story

The visualizations make it easier to compare book prices, understand
rating composition, identify expensive books, and examine relationships
between variables.

The dashboard combines multiple charts into a single view, making the
data easier to interpret and communicate.

## ✅ Conclusion

The project demonstrates how raw data can be transformed into meaningful
visual stories using Python visualization libraries.

Matplotlib and Seaborn were used to create visually appealing charts
that communicate patterns clearly and support data-driven understanding.

The final dashboard provides a portfolio-ready presentation of the
book dataset.
